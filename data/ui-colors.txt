# Color swaps for the game's flat-colored menu shapes, the ones custom
# textures can't change because they have no texture of their own (the
# music ticker's bar, border and tab; the main menu's red bars). This also
# changes the tint of textured menu shapes in that exact color.
#
#   RRGGBB => RRGGBB          (the shape keeps its own see-through-ness)
#   RRGGBB => RRGGBBAA        (AA sets it: 00 invisible, FF solid)
#
# - Colors are hex, red green blue, like in an image editor ("#" in front
#   is fine: #DC3D00 => #2060C0).
# - Every shape in that exact color changes, on any screen.
# - Each color changes once: "A => B" and "B => C" turn A into B, not C.
# - Lines starting with "# " (hash and a space) are ignored. Remove the "# "
#   from a line to use it. Changes take effect the next time the game starts.
# - play.ps1 makes this file from data\ui-colors.txt if it is missing: delete
#   it to get the game's own colors back.
# - The startup report says how many swaps were read ("ui colors:").

# The music ticker:
# DC3D00 => DC3D00    # the bar (orange)
# DCA500 => DCA500    # the border (gold)
# A80000 => A80000    # the tab on the right (red)
# 740000 => 740000    # the tab's shaded side (dark red)
# B45153 => B45153    # the tab's lit edge (pink)

# The main menu's red bars behind the button rows (outer see-through part
# and inner solid part share this color):
# 500000 => 500000

# The main menu's red bar under the logo (and the panel behind the logo,
# which shares the color):
# 640000 => 640000
